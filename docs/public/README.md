# Public Documentation

This directory contains publication-oriented summaries. It intentionally
excludes local database identities, record counts, account identifiers, file
paths, resume metadata, backup destinations, and maintenance observations.

The detailed working reports elsewhere in `docs/`, along with
`backend/APPLY_SECURITY_PATCH (3).md` and the root production-readiness
documents, are retained as working material. Review them separately and do
not publish them as a group.

Provider plans and terms change. Provider-specific statements in these
summaries are decision records, not guarantees, legal advice, or current
quotations. Confirm current official terms, quotas, eligibility, and pricing
before selecting a service.
